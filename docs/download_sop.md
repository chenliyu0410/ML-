# 資料下載 SOP（人工執行）

> **為什麼是人工**：關港貿單一窗口與國際貿易署貿易統計網**兩個系統都有驗證碼**，
> 已實測確認無法寫爬蟲。本專案因此沒有 `fetch_customs.py`，改為
> 「人工下載 → `parse_downloads.py` 解析合併」。
>
> 這不是妥協，是把限制寫進架構。接受季度人工更新，把 SOP 寫到別人照著也能重跑。

目標產出：`月 × 稅號 × 國家` 的完整 panel。

---

## 一、主資料下載（管道 A：關港貿單一窗口）

選管道 A 是因為**它能直接輸出 CSV**，管道 B 只有 XLS/ODF/PDF/JPG。

🔗 https://portal.sw.nat.gov.tw/APGA/GA30

### 標準設定（每次都要一模一樣）

| 欄位 | 選擇 |
|---|---|
| 進出口別 | **進口總值(含復進口)** ← 之後在 `clean.py` 扣除復進口 |
| 資料週期 | **按月** |
| 資料期間 | **2016-01 ~ 最新月**（民國105年起口徑一致） |
| 貨品別 | **指定貨品號列** → 貼上 `23091000002,42050090104` |
| 國家(地區)別 | **全部國家** |
| 統計值 | **金額(美元) + 金額(新臺幣) + 重量(公斤)** 全選 |
| 輸出模式 | **下載CSV** |

> 💡 號列字串不要手打。用程式產生，避免打錯一碼卻查不出來：
> ```bash
> python -c "from src import config; print(config.hs_query_string())"
> ```

> ⚠️ 統計值務必**三個都選**。美元與新臺幣同時有，才能做匯率效果的交叉驗證；
> 重量要選**公斤**不是公噸，單位搞混是對帳失敗的常見原因。

### 分批策略

單次查詢有筆數上限。`10 年 × 12 月 × 200 國 × 2 稅號` 很可能超過，因此：

```
按「年」分批下載
  → 每年一個 CSV
  → 檔名統一為 import_YYYY.csv     ← parse_downloads.py 靠這個 pattern 掃檔
  → 放進 data/raw/
```

檔名不照規則，`parse_downloads.py` 會掃不到。命名一致比什麼都重要。

### 下載後立刻做

1. 開檔確認**筆數不是剛好等於上限**——若是，代表被截斷了，要再切細（改成半年一批）
2. 在 `data/raw/MANIFEST.md` 補一列紀錄（見下方）

## 二、對帳資料下載（管道 B：貿易統計網）

🔗 [進出口值表(按貨品) FSC3020F](https://publicinfo.trade.gov.tw/cuswebo/FSC3000C?table=FSC3020F)

管道 B 有**內建「平均單價(重量)」報表**，系統直接算好 USD/kg。
抓同一組稅號、同一期間，存成 `data/raw/channel_b_unit_price.xls`。

管道 B 的其他優勢（Phase 2 可能用得上）：

| 優勢 | 說明 |
|---|---|
| 資料回溯到 1989 年 | 遠早於管道 A |
| 號列支援 2/4/6/8/11 碼區間查詢 | 可一次抓整個 2309 節 |
| 國家別分組完整 | 洲別、東協 / RCEP / CPTPP / 歐盟、單一國別 |
| 復運資料可分離 | 含復運 / 不含復運 / 單獨復運 |

> ⚠️ 用管道 B 時，分析進口需求請選**「不含復運資料」**。

## 三、驗證步驟（別跳過）

拿管道 B 的官方平均單價，跟自己用 `value_usd / weight_kg` 算的結果對照：

```bash
python -m src.data.parse_downloads --reconcile
```

**兩者對不起來，代表口徑錯了。** 依機率排序的常見原因：

1. **復進口沒扣除** — 管道 A 下載的是「含復進口」
2. **幣別搞混** — 用了 TWD 欄位卻當成 USD
3. **重量單位搞混** — 公噸 vs 公斤，差 1000 倍
4. **稅號範圍不一致** — 對帳時只抓了 2309.10，漏了 4205

這個對帳只要做一次，卻能擋掉整份分析最致命的錯誤。
沒過就不要往下做，帶著錯的口徑跑完模型，後面全部要重來。

## 四、下載紀錄（MANIFEST）

人工下載最大的風險是**三個月後沒人記得當初選了什麼**。
每次下載都在 `data/raw/MANIFEST.md` 補一列，欄位如下：

| 檔名 | 下載日期 | 管道 | 期間 | 稅號 | 進出口別 | 筆數 | 下載者 |
|---|---|---|---|---|---|---|---|

`data/raw/` 的資料檔不進版控，但 `MANIFEST.md` 進版控 ——
別人拿到 repo 才知道該去下載什麼、以及你的數字是怎麼來的。

---

## 五、更新頻率

海關統計約次月中旬發布。建議**每季更新一次**：

1. 下載當年度最新的 `import_YYYY.csv`（覆蓋舊檔，因為當年度資料會逐月增補）
2. 更新 MANIFEST
3. 重跑 `parse_downloads` → `clean` → `build_features`
4. 重新對帳

> ⚠️ 當年度的檔案每次都要重下，不能只補新月份 ——
> 海關會回頭修正前幾個月的數字，舊檔的尾端可能已經過期。
