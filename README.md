# 🐾 台灣寵物食品進口分析與需求預測

> 以海關月度進出口資料為基礎，驗證「寵物食品精緻化」假設，並建立來源國 × 品項的進口需求預測與採購建議模型。

## 📌 專案動機

初步觀察顯示，台灣寵物食品的**進口總金額逐年上升，但進口總重量逐年下降**。

若此現象為真，代表單位重量價格（USD/kg）持續攀升 —— 市場正朝**高單價、精緻化**方向移動。

但單價上升有多個競爭性解釋，**本專案的第一項任務就是排除這些干擾，確認精緻化是否真實存在**：

| 競爭解釋 | 排除方式 |
|---|---|
| 通貨膨脹 | 以進口物價指數（IPI）/ CPI 平減，改看**實質單價** |
| 匯率變動 | 同時以 USD 與 TWD 計價交叉驗證 |
| 國際運費、原物料上漲 | 對照玉米、雞肉、SCFI 運價指數走勢 |
| 稅則號別改編 | 檢查 HS 版本切換年度（2017 / 2022）是否造成斷點 |
| **整體物價普遍上漲** | 對照「一般食品類」進口單價指數，比較**相對漲幅** |

> 🔑 唯有寵物食品的實質單價漲幅**顯著高於**整體食品，「精緻化」的結論才成立。

## 📊 資料來源

### 🚨 重要前提：**兩個官方查詢系統都有驗證碼（CAPTCHA），無法寫爬蟲**

已實測確認，這直接決定專案架構 —— **資料取得必須是「人工下載 + 程式解析」，不是「自動爬取」**。

| 國家別 | 合計 / **全部國家** / 指定國家 ✅ |
| 統計值 | 金額(美元) / 金額(新臺幣) / 重量(公噸) / **重量(公斤)** / 數量(限11碼) |

> 💡 105 年起採一般貿易制度，103–104 年為回溯資料，更早期口徑不同 —— **建議資料起點設在 2016-01（民國105年）**。

#### 管道 B：國際貿易署－貿易統計網 ⭐ 推薦

## 🔢 稅則號別（HS Code）—— ⚠️ 這是全專案最容易做錯的一步

**寵物食品沒有單一稅號可以一次抓完。** 號列選錯，後面所有分析全部作廢。

### ✅ 已確認的核心號列（依防檢署「犬貓寵物食品輸入檢疫條件」官方定義）

| CCC 號列 | 貨名 | 單位 | 關稅 | 簽審規定 |
|---|---|---|---|---|
| **`2309.10.00.00-2`** | 供零售用之貓狗食品<br>*Dog or cat food, put up for retail sale* | KGM | 2% | B01、MP1 |
| **`4205.00.90.10-4`** | 由動物皮製成供寵物嚼咬之製品 | — | — | B01 |

> 🚨 **`4205.00.90.10-4` 是本專案最重要的發現。**
> 寵物咬膠、潔牙骨、牛皮骨這類「寵物零食」**不在食品章（第 23 章），而是歸在皮革章（第 42 章）**。
> 這正是我先前警告的那種陷阱 —— 只抓 2309.10 的話，**整個寵物零食品類會憑空消失**，
> 而零食恰好是精緻化程度最高、單價最貴的品類，漏掉會讓你的核心結論嚴重失真。

主管機關的檢疫條件把「犬貓食品」明確定義為含偶蹄目或禽鳥類動物性成分、供犬貓食用或嚼咬，且歸屬上述兩個號列的產品 —— **這是最權威的品類邊界定義，直接引用即可，不必自己揣測。**

### 🔍 簽審規定的額外情報價值

| 代號 | 意義 | 對分析的用處 |
|---|---|---|
| **B01** | 須憑防檢署檢疫合格證始准進口 | 代表**另有一份輸入檢疫核准紀錄**可交叉比對，是潛在的差異化資料源 |
| **MP1** | 大陸物品有條件准許輸入 | 中國大陸來源**僅開放「乾狗糧（牛肉口味）」一項**（EX 註記）→ **中國的進口數字天生受管制壓抑，建模時應視為結構性因素而非市場偏好** |

> 💡 MP1 這條非常關鍵：如果不知道這個管制，看到中國進口量偏低會誤判成「台灣消費者不愛中國品牌」，
> 但真相是**法規根本不讓進**。這種只有領域知識才看得出來的事，就是你相對於其他人的優勢。

### 🔎 仍需自行查證的擴充號列

| 可能品項 | 可能落在 | 狀態 |
|---|---|---|
| 寵物肉乾 / 肉條（非皮製） | `1602` 調製肉類 | ❓ 待查 |
| 寵物保健品 / 營養補充 | `2106` 或 `3004` | ❓ 待查 |
| 散裝、非零售包裝寵物飼料 | `2309.90` | ❓ 待查，需人工判讀分項 |
| 貓砂 | `2508` / `3824` / 其他 | ❓ 非食品，建議 Phase 1 排除 |

### 執行步驟

1. 上 [稅則稅率綜合查詢 GC411](https://portal.sw.nat.gov.tw/APGQ/GC411)，或用 [貨品歸屬稅則查詢系統](https://hscode.customs.gov.tw/)（支援中文品名模糊搜尋，較好用）
2. 以關鍵字（狗、貓、寵物、飼料、嚼咬、pet）反查，補齊上表待查項目
3. 台灣用 **11 碼 CCC 號列**＝ HS 6 碼 + 稅則 2 碼 + 統計 2 碼 + 檢查碼 1 碼
4. 將最終清單與**納入/排除理由**寫進 `config/hs_codes.yaml`
5. ⚠️ 檢查 HS 改版年度（2017 / 2022）是否造成號列斷點

> 💡 **這一步就是本專案的護城河。** 模型誰都能跑，但「知道 2309.90 裡哪些分項才算寵物食品」需要領域知識 —— 把判斷理由完整記錄在 config 裡，它比模型更有價值。

## 📥 資料下載 SOP（因有驗證碼，此步驟人工執行）

目標：湊出 `月 × 稅號 × 國家` 的完整 panel。建議用**管道 A（關港貿單一窗口）**，因為它能直接輸出 CSV。

### 標準設定

| 欄位 | 選擇 |
|---|---|
| 進出口別 | **進口總值(含復進口)** ← 之後在清理階段扣除復進口 |
| 資料週期 | **按月** |
| 資料期間 | **2016-01 ~ 最新月**（民國105年起口徑一致） |
| 貨品別 | **指定貨品號列** → 貼上 `23091000002,42050090104`（逗號分隔） |
| 國家(地區)別 | **全部國家** |
| 統計值 | **金額(美元) + 金額(新臺幣) + 重量(公斤)** 全選 |
| 輸出模式 | **下載CSV** |

### 分批策略

單次查詢有筆數上限，`10 年 × 12 月 × 200 國 × 2 稅號` 很可能超過。建議：

```
按「年」分批下載 → 每年一個 CSV → 檔名統一為 import_YYYY.csv
                 → 放進 data/raw/
                 → 由 parse_downloads.py 批次讀取合併
```

### 驗證步驟（別跳過）

下載完後，用**管道 B 的「平均單價(重量)」報表**抓同一組稅號、同一期間的官方單價，
和你自己用 `value_usd / weight_kg` 算出來的結果對照。

> 🔑 **兩者對不起來，代表你的口徑錯了**（多半是復運沒扣、或幣別搞混）。
> 這個對帳只要做一次，卻能擋掉整份分析最致命的錯誤。

## 📐 資料規格（processed panel）

建模用的最終資料應為**長格式 panel**：

| 欄位 | 型態 | 說明 |
|---|---|---|
| `ym` | date | 年月（YYYY-MM），主時間鍵 |
| `hs_code` | str | 稅則號別 |
| `country` | str | 生產國家（進口）|
| `value_usd` | float | 進口值 |
| `weight_kg` | float | 進口重量 |
| `unit_price` | float | `value_usd / weight_kg` ← **核心衍生欄位** |
| `unit_price_real` | float | 經 IPI 平減後的**實質單價** |

**唯一鍵**：`(ym, hs_code, country)`

> 🔑 **為什麼一定要用月資料**：年度資料從 2016 年起只有約 10 個點，任何 ML 模型都無法訓練。
> 改為 `月 × 稅號 × 國家` 的 panel 後，樣本數可從 10 筆放大到數萬筆，樹模型才有東西可學。

### 清理注意事項

- **國名標準化**：中國大陸 / 中國 / CHINA、美國 / USA 等寫法不一致，需建對照表
- **零值 vs 缺失**：某月某國沒有進口 → 應補 0 而非 NaN（會影響 lag 特徵）
- **稀疏序列處理**：交易月數 < 24 個月的國家 × 品項組合，建議先剔除或併入「其他」
- **離群值**：單筆超大金額可能是轉口或報關異常，用 IQR 檢查但**不要輕易刪除**，先查原因

## 🛠️ 特徵工程清單

| 類別 | 特徵 |
|---|---|
| **落後項 Lag** | `lag_1, lag_2, lag_3, lag_6, lag_12`（量、值、單價各一組） |
| **滾動統計** | `rolling_mean / std`（窗口 3, 6, 12）→ 捕捉趨勢與波動度 |
| **成長率** | MoM、YoY、12 個月 CAGR |
| **季節性** | `month`、`quarter`、月份的 `sin/cos` 週期編碼 |
| **市場結構** | 該國市占率 `share`、市占變化、HHI 集中度指數 |
| **類別編碼** | `country` 用 Target Encoding 或 LightGBM 原生 categorical |
| **外部變數** | USD/TWD 匯率、CPI、玉米/雞肉價格、SCFI 運價 |
| **事件 dummy** | COVID 期間、貿易協定生效、稅則改版年度 |

> ⚠️ **防資料洩漏**：所有 lag 與 rolling 特徵**只能用 t 時點以前的資料**。
> 標準化、Target Encoding 一律封裝進 `sklearn.Pipeline`，且只用訓練集擬合參數。

## 🤖 建模策略

### 三層遞進

```
① Baseline（一定要做，用來當比較基準）
   ├─ Naive：預測值 = 上期值
   └─ Seasonal Naive：預測值 = 去年同月值   ← 有季節性時很難打敗

② 統計時間序列
   ├─ SARIMA
   └─ Prophet                              ← 可解釋趨勢與季節分量

③ 機器學習（主力）
   └─ LightGBM / XGBoost 全域模型
      把所有國家 × 品項的序列疊在一起訓練一個模型，
      用 country / hs_code 當特徵區分 → 資料量放大，稀疏序列也能學
```

> 🔑 **Baseline 不是形式**：實務上很多時間序列專案的複雜模型打不贏 Seasonal Naive。
> 若 LightGBM 沒有明顯優於 baseline，那個結論本身就要誠實寫進報告。

### 分群模組（回答「該進口哪一國、哪一類」）

```
每個「國家 × 品項」組合 →
特徵向量 [單價水位, 單價 CAGR, 進口量 CAGR, 市占率, 市占變化, 波動度, 集中度]
        ↓ 標準化（K-Means 靠距離，必須做）
        ↓ PCA 降維
        ↓ K-Means（手肘法定 K + 輪廓係數驗證）
        ↓
   高單價高成長 ← 採購建議名單
   高單價停滯 / 低價走量 / 衰退
```

## 📏 評估與驗證

### 驗證策略

⚠️ **時間序列絕對不能用 `train_test_split` 隨機切分** —— 那等於用未來預測過去。

```
使用 TimeSeriesSplit（滾動原點回測）：

第 1 折  [====train====][val]
第 2 折  [======train======][val]
第 3 折  [========train========][val]
                                  ...

最後 12 個月完全保留為 holdout，全程不碰，最終只評估一次
```

### 指標

| 任務 | 指標 |
|---|---|
| 預測（迴歸） | MAE、RMSE、MAPE / sMAPE、**相對 baseline 的改善率** |
| 分群 | 輪廓係數（越接近 1 越好）、DB 指數（越小越好）、**+ 商業可解釋性人工判斷** |
| 分類（選配） | Precision / Recall / F1 / AUC |

> 💡 MAPE 在實際值接近 0 時會爆炸，稀疏序列建議改用 sMAPE 或 MASE。

## ⚠️ 已知風險與陷阱

| 風險 | 說明 | 因應 |
|---|---|---|
| **漏抓 4205 零食** | 單價最高的品類整個消失，精緻化結論失真 | 兩個核心號列都要抓 |
| **復運沒扣** | 高估進口需求 | 管道 A 分離復進口，或管道 B 選「不含復運」 |
| **忽略 MP1 管制** | 誤把法規限制當市場偏好 | 中國來源需單獨標記為受管制 |
| **無法自動更新** | 兩系統皆有驗證碼 | 接受人工季度更新，SOP 寫清楚 |
| **稅號選錯** | 整份分析報廢 | Phase 0 花時間查證，理由寫進 config |
| **HS 版本斷點** | 2017 / 2022 改版造成序列不連續 | 建新舊對照表，或分段分析 |
| **資料洩漏** | 隨機切分、用未來資訊算特徵 | TimeSeriesSplit + Pipeline 封裝 |
| **樣本稀疏** | 小國家單一品項只有零星幾筆 | 設最低交易月數門檻，或併為「其他」 |
| **資訊保護遮罩** | 關務署對可能揭露個別廠商的資料做保護處理 | 檢查是否有異常空值或合併項 |
| **打不贏 baseline** | 複雜模型未必更好 | 誠實呈現，這本身是有效結論 |
| **範圍蔓延** | 想同時做出口、動物用藥 | 嚴守本階段只做進口食品 |
